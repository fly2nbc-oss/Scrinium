# Interface glossary

Fixed terms for the five interface languages (`src/i18n/`). When you translate or write texts, use these words so the same button has the same name everywhere.

**Form of address:** German *du*, English *you*, French *vous*, Spanish *tú*, Italian *tu*.
**Punctuation:** dash with spaces ` – `; ellipsis with a space before it (`Durchsuchen …`, `Browse …`); quotation marks German „…“, English “…”, French « … », Spanish and Italian «…».
**Not translated:** instructions to the AI, word lists (document types, keywords, synonyms), configuration defaults, keys in TOML files and environment variables, the command line, tests.
